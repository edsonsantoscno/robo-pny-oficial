# 🤖 ROBÔ COPY TRADER - SOLBRL

Robô de trading automático com suporte a copy trader para múltiplos clientes. Baseado em **Média Móvel (7 e 40 períodos)** com gerenciamento de risco por **banca**.

## 📋 Características

✅ **Trader executa operações** baseadas em estratégia técnica
✅ **Copy Trader automático** - Clientes replicam operações do trader
✅ **Gerenciamento de risco por banca** (não por operação)
✅ **Stop Loss: -5%** do preço de entrada (pausa até 00:01)
✅ **Meta Diária: +2%** da banca (pausa até 00:01)
✅ **Sinais em JSON** - Fácil integração
✅ **Clientes podem ajustar:**
   - Quantidade (50%, 100%, 200%, etc)
   - Stop Loss próprio
   - Meta diária própria
✅ **Logs estruturados** - Rastreamento completo
✅ **Pronto para live** - Seguro para operações reais
